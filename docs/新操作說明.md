# 《浩劫殘陽：破碎大地》繁體中文版：新增的操作方式

這個中文版除了翻譯之外，還加入了幾項比較接近現代遊戲的操作方式。原本的操作全部保留，想用原版方式玩也完全沒問題。

## 一、遊標模式快速鍵

原版要按滑鼠右鍵，在「行走 → 攻擊 → 觀察」之間循環切換。現在可以用鍵盤直接切換：

| 按鍵 | 功能 |
|---|---|
| **空白鍵** | 行走遊標 |
| **A** | 攻擊遊標 |
| **S** | 觀察遊標 |
| **T** | 開啟／關閉動畫（原版是 A 鍵） |

- 右鍵循環仍然可以用。
- 在背包等畫面裡，空白鍵保留原本的功能。

## 二、行走遊標會自動判斷要做什麼

**不在戰鬥中**時，大部分操作只需要用行走遊標：

- **滑鼠移到人物、門、箱子等可以互動的東西上**，遊標會變成眼睛，表示點下去會互動。
- **點一下**：
  - 如果就站在旁邊：直接互動（開啟資訊卡，或直接開門）。
  - 如果離得比較遠：隊伍會走過去，**到了之後自動互動**。
- **按住 Ctrl 再點**：只走過去，不互動。例如想站到上鎖的門旁邊，再用攻擊把它打破。
- 點地面、點自己的隊員，都照常行走。

## 三、觀察遊標與攻擊遊標也會自動走過去

**不在戰鬥中**時：

- **觀察遊標**點太遠或被擋住的東西，不會再出現「TOO FAR AWAY」「NO LINE OF SIGHT」，而是走過去，到了之後自動互動。
- **攻擊遊標**點近戰搆不到的目標（例如遠處的門或敵人），會走到旁邊再攻擊。
  - 如果角色準備了弓、投石索等遠程武器，遠處的目標照原版直接射擊。
- 用這兩種遊標開始走過去時，遊標會自動切回行走。這是因為原版遊戲只有在行走遊標下，人物才會移動。

## 四、戰鬥中維持原版規則

戰鬥中的所有操作都和原版一樣，上面這些自動走過去的功能都不會啟動。原因是戰鬥中移動要消耗移動力，自動走位會改變戰鬥的結果。

- 行走遊標點敵人：走過去攻擊（原版功能）。
- 觀察遊標點太遠的目標：顯示原版的訊息，不移動。

## 小提醒

- 遊標圖示只在滑鼠移動時更新。滑鼠停在物件上、只按下或放開 Ctrl 時，圖示要動一下滑鼠才會改變。
- 會走動的人物，如果隊伍走到時對方已經離開，就不會自動互動；再點一次即可。

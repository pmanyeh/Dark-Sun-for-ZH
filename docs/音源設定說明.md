# 《浩劫殘陽：破碎大地》繁體中文版：音源設定（MT-32、General MIDI、聲霸卡）

1993 年的 DOS 遊戲要靠音效卡或外接音源器播放音樂，這款遊戲為每一種音樂硬體**分別編寫了一套音樂**。同一首曲子用 Roland MT-32、General MIDI 和聲霸卡的 FM 合成播放，聽起來差別非常大。

整合包內附的 DOSBox-X 三種都能模擬，用「音效設定.bat」就能切換。音效（刀劍、腳步、法術等數位音效）一律由聲霸卡播放，不受影響。

## 一、三種音樂音源

| 音源 | 需要準備 | 說明 |
|---|---|---|
| General MIDI（預設） | 不用（可加 SoundFont） | Steam 版的預設設定。用 Windows 內建的 Microsoft GS Wavetable Synth 播放；在 soundfonts 資料夾放一個 SoundFont，就改用 FluidSynth 播放 |
| Roland MT-32 | MT-32 的 ROM | 模擬 Roland MT-32／LAPC-1 音源器，播放遊戲專為 MT-32 編寫的音樂與音色 |
| 聲霸卡（FM 合成） | 不用 | 模擬 Sound Blaster 的 FM 合成音色，是當年許多玩家聽到的版本 |

## 二、用「音效設定.bat」切換

雙擊整合包裡的 **「音效設定.bat」**，會開啟遊戲原版的英文設定程式（SSI Sound Installer）。用**方向鍵或選項旁的字母鍵**選擇，按 **Enter** 確定。

第一個畫面會顯示「A SoundBlaster Pro 16 ASP Has Been Detected」，按 Enter 繼續。接著會問「Would You Like to Use One Sound Card for Music And Another for Digital Sound Effects?」（音樂和音效要不要用不同的卡），依照想要的音源操作：

### 改用 MT-32

1. 選 **YES**（按左方向鍵，再按 Enter）。
2. 「Select a Source for Music」選 **B　Roland LAPC 1, MT-32, MPU 401**。
3. 「Select a Source for Digital Sound Effects」選 **A　SoundBlaster Pro III**。
4. 確認畫面選 **YES**，等出現「Sound Init Saved...」，按 Enter，視窗就會關閉。
5. 把 MT-32 的 ROM 放進 mt32-roms 資料夾（見第三節）。

### 改回 General MIDI（Steam 版的預設）

1. 選 **YES**（按左方向鍵，再按 Enter）。
2. 「Select a Source for Music」選 **A　Roland SCC-1, General Midi**。
3. 「Select a Source for Digital Sound Effects」選 **A　SoundBlaster Pro III**。
4. 確認畫面選 **YES**，等出現「Sound Init Saved...」，按 Enter。

### 改用聲霸卡（FM 合成）

1. 選 **NO**（直接按 Enter）。
2. 「Select a Sound Source」選 **E　SoundBlaster Pro 16 ASP**。
3. 「Are Sound Card(s) Installed At The Default Settings?」選 **YES**。
4. 確認畫面選 **YES**，等出現「Sound Init Saved...」，按 Enter。

設定程式選單裡還有其他音效卡（Gravis、Aria、Media Vision 等），整合包的 DOSBox-X 設定沒有啟用它們，請不要選。

## 三、MT-32 的 ROM

MT-32 模擬器需要原機的 ROM。ROM 有版權，**整合包不附**，請使用你自己合法取得的檔案，放進整合包的 **mt32-roms** 資料夾：

- MT32_CONTROL.ROM 和 MT32_PCM.ROM（MT-32），或
- CM32L_CONTROL.ROM 和 CM32L_PCM.ROM（CM-32L）

檔名必須完全相同（大小寫沒關係）。

## 四、General MIDI 改用 SoundFont（FluidSynth）

Windows 內建的音源音色比較單薄。想要更好的 General MIDI 音色，可以把一個 SoundFont 檔（.sf2 或 .sf3）放進整合包的 **soundfonts** 資料夾，遊戲就會改用 FluidSynth 播放。網路上有許多免費的 SoundFont，例如 GeneralUser GS；設定程式把 General MIDI 列為 Roland SCC-1（Sound Canvas），選模仿 Sound Canvas 的 SoundFont 會比較接近當年的聲音。

- **檔名請用英文**，含中文的檔名 DOSBox-X 讀不到。
- 放了好幾個時，用檔名排序第一個。
- 想改回 Windows 內建音源，把 SoundFont 移出這個資料夾即可。

## 五、「玩遊戲.bat」怎麼決定用哪個音源

每次啟動時，「玩遊戲.bat」和「玩遊戲（除錯模式）.bat」會先讀取「音效設定.bat」存下的設定，自動選擇 DOSBox-X 的音源，不用改任何設定檔：

| 音效設定選的音樂 | 資料夾裡的檔案 | 實際播放 |
|---|---|---|
| MT-32 | mt32-roms 有 ROM | MT-32 模擬 |
| MT-32 | mt32-roms 沒有 ROM | Windows 內建音源（音色會不對，黑色視窗會顯示提醒） |
| General MIDI | soundfonts 有 SoundFont | FluidSynth |
| General MIDI | soundfonts 沒有 SoundFont | Windows 內建音源 |
| 聲霸卡 | 不需要 | FM 合成 |

啟動時的黑色視窗會顯示這次用的是哪一種音源。

## 六、常見問題

- **選了 MT-32，音樂聽起來很怪**：mt32-roms 裡沒有 ROM，或檔名不對。放好 ROM，或用「音效設定.bat」改回 General MIDI。
- **想恢復成 Steam 版原本的設定**：照第二節「改回 General MIDI」操作。
- **音效設定會影響中文化或存檔嗎**：不會。設定只存在遊戲資料夾的 SOUND.CFG，「解除中文化.bat」也不會改動它。

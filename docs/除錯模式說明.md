# 《浩劫殘陽：破碎大地》繁體中文版：除錯模式（作弊模式）

原版遊戲留有一個給開發人員用的除錯模式，要在啟動時加上命令列參數 -k911 才會開啟。開啟後有加金錢、加經驗值、穿牆查看等作弊功能。中文化保留了原版除錯模式的全部功能，另外加了一項「地圖傳送」。

這是原版程式本來就有的隱藏功能，不是正常玩法。會讓遊戲變得太簡單，也可能打亂劇情進度，**使用前請先存檔，建議另外用一個存檔欄位**。

## 一、怎麼啟動

雙擊整合包裡的 **「玩遊戲（除錯模式）.bat」**。它和「玩遊戲.bat」完全一樣，只是啟動遊戲時多加了 -k911。

- 用同一份遊戲與存檔，兩種模式可以隨時切換：關掉遊戲，改用另一個啟動檔即可。
- 畫面上沒有任何「已進入除錯模式」的提示，按下面的按鍵有反應就表示開啟了。
- 一般模式（「玩遊戲.bat」）下，這些按鍵都沒有作用。

## 二、原版的除錯功能

以下是原版程式本來就有的功能，中文化沒有改動它們的行為。

### 已實際測試過

| 按鍵 | 功能 |
|---|---|
| **S** | 金錢增加 1,000 |
| **T** | 全隊增加經驗值 |
| **F6** | 在地圖上顯示格線，再按一次關閉 |
| **按住 Shift 點擊** | 用觀察遊標點被牆擋住或太遠的東西，也能查看；路徑走得到時，隊長會走過去再互動 |

- 這些按鍵在地圖畫面（沒有開背包等視窗時）使用。
- 手冊寫 F6 是「動畫開關」，但原版程式實際上把 F6 留給了除錯功能，所以一般模式按 F6 沒有反應。要開關動畫請按 **A**。

### 依程式分析，尚未實際確認

以下功能是從原版程式碼找到的，還沒有在遊戲中逐一測試，效果可能和描述不同：

| 按鍵 | 功能 |
|---|---|
| **Alt+F2** | 調高隊長的屬性 |
| **Alt+F4** | 學會全部法術 |
| **Alt+F1** | 切換某個除錯開關（用途不明） |
| **M**、**?**、**=** | 除錯用途，作用不明 |

## 三、中文化新增：地圖傳送

原版的除錯模式沒有傳送功能，中文化另外加入了地圖傳送：

1. 在地圖上按 **O** 開啟俯瞰地圖。
2. **按住 Shift，點地圖上的位置**，全隊就會傳送過去，畫面也跟著移過去。

- 不按 Shift 時，點地圖照原版只捲動畫面。
- 點到牆裡或水裡時，隊伍會自動落在附近可以站的地方。
- 只能在同一個區域內傳送；**戰鬥中不能傳送**。
- 一般模式下按住 Shift 點地圖，也只會捲動畫面，不會傳送。

## 四、除錯模式下的遊標

中文化的遊標熱鍵（Z／X／D）和行走遊標的自動走過去，在除錯模式下照常可用。

只有一個例外：**觀察遊標**點太遠或被擋住的東西時，除錯模式維持原版的規則，顯示 TOO FAR AWAY 或 NO LINE OF SIGHT，按住 Shift 才會放行。這是為了保留原版除錯模式「按住 Shift 穿牆查看」的行為。一般模式下則會自動走過去。

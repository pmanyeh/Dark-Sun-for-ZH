# 名稱一致性檢查（2026-09-26）

起因：替 `SEGOBJEX.GFF` 的生物／NPC 名字擬譯名時，使用者要求**最優先確認前後一致**。
因此先掃過所有已翻譯的資源，統計每個名詞實際用了哪些譯法。

- 掃描範圍：`localization_manifest.csv` 的 dialogue／name（NAME-1）／spin／text／merr，
  以及 `exe_spell_names.csv`、`exe_effect_names.csv`、`fixed_ui_labels.csv`。
  SPIN 出貨包的 `manifest_sha256` 與目前的 manifest 相同，所以 manifest 就是 SPIN 的來源。
- 比對方式：英文含該詞（含複數、所有格、複合詞）的條目，看中文裡出現哪個譯法。
  數字是「條目數」，不是出現次數。
- 生物名字的逐項草稿在 `localization/catalog/creature_names.csv`（`needs_decision=是` 的要決定）。

## 其他

- 入隊角色 Gerakis／Cermak／Cilla／K'ratchek 不翻（使用者 2026-09-26 決定）。
- 修改對話譯文時，要同步 4 個檔案（見 handoff 第 5 節），並重建對話封包。
  NAME-1、SPIN、EXE 法術名各有自己的建置步驟。
- 通用詞（Guard、Slave、Warrior、Villager）在對話裡的變化有些是行文需要（例如「勇士們」），
  是否也要統一，由使用者決定範圍。

## 處理結果（2026-09-26，v144）

使用者決定：

- B 類一律依權威檔。權威檔自相矛盾或並列兩種譯名的，取遊戲中用得最多的那個，並把權威檔修成單一譯名（v5.5）。
- C 類拿掉連字號：楚爾特通克、克利克通克（對話一併改）。Wyvern Master 音譯為「威弗恩大師」。
- 入隊角色不翻。

執行：`tools/unify_glossary_terms.py` 改寫 399 個條目（對話、NAME-1、SPIN、固定介面標籤）。
英文用語不同者各自統一：`Tari`＝塔里鼠人；`ratman`（他人的稱呼，常是辱罵）維持「鼠人」。
兩個選項因變長超過 49 bytes，改寫為「巴爾卡札騙了你們！起義反抗吧！」「塔里鼠人為何追隨米奎茲爾？」。

尚未處理的權威檔並列條目（不影響這次的生物名字）：Thief（小偷 / 盜賊，使用者已定「小偷」）、Cedrilte、Astral Plane、
So-Ut、Sink Worm、Turn Undead、Terror Bloom、Magera。
